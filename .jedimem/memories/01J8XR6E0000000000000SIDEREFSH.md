A custom git ref cannot be the sharing mechanism between teammates — only a
staging area.

**Why:** `refs/jedimem/*` pushes and fetches fine, but `git clone` and `git fetch`
follow only the default refspec, so a teammate who clones normally sees **zero**
memories. Verified: a fresh clone showed nothing until an explicit
`git fetch origin 'refs/jedimem/*:refs/jedimem/*'`.

**How to apply:** use the side ref for lock-free local capture staging, and share
through ordinary committed files on an ordinary branch. The review gate belongs
exactly at that boundary.
