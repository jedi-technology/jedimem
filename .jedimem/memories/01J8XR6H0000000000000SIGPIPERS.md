A Rust CLI must reset SIGPIPE to SIG_DFL, or piping it into `head` panics.

**Why:** Rust sets SIGPIPE to SIG_IGN at startup, so writing to a closed pipe
returns EPIPE and the `println!` family *panics*. `jedimem list | head -1`
crashed with `failed printing to stdout: Broken pipe` and a backtrace. After the
fix the process exits 141 (128 + SIGPIPE), which is exactly what `head` expects.

**How to apply:** call `libc::signal(libc::SIGPIPE, libc::SIG_DFL)` as the first
statement in `main`. Test it with output large enough to fill the pipe buffer —
a short output fits entirely and never triggers EPIPE, so a small test passes
while the bug is still there.
