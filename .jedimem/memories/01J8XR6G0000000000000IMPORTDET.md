Brownfield import is deterministic and offline: no importer may call an LLM.

**Why:** a team evaluating jedimem must be able to run `jedimem import` on a
private repo, read every proposed memory, and diff it — with nothing leaving the
machine and no model in the loop. An import step that phones a provider is one a
security review will block, and it would gate day-one value behind a key.
Instruction files, ADRs, CODEOWNERS and revert commits are all structured enough
to parse directly.

**How to apply:** keep LLM extraction for *live sessions* only, where there is no
deterministic alternative. Everything imported lands as `proposed`, never
`active` — a hand-written rule was authored by a human, but it was not reviewed
*as a memory*, and those are different acts.
