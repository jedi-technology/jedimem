Memory extraction must be batched in a background process, never run per turn
from a hook.

**Why:** a headless coding-agent invocation bills its entire system prompt and
tool-definition block on every call. Measured on `claude -p`: **27,595 tokens and
$0.0208 to answer "ok"**. A real extraction over a 3-line transcript cost
$0.0223 — meaning 93% of the spend was fixed overhead. `--disallowedTools` does
not reduce it; denying a tool removes the permission, not the definition.

**How to apply:** batch into windowed calls (~30 min). At ~120 human turns/day
that is $0.17/day instead of $2.52/day for identical output. Always redirect stdin
(`< /dev/null`) or the process blocks 3 s on a stdin timeout. Force a tool call
with a JSON Schema — asked for JSON in prose, the model returns a fenced block
inside a string and free-styles field types.
